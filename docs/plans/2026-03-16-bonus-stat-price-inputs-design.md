# 추가옵션(추옵) 강환/영환/심연 가격 입력 설계

## 목표

- 아이템 강화 비용 분석(item-scouter)의 **추가옵션 설정**에서, 강력한 환생의 불꽃(강환)·영원한 환생의 불꽃(영환)·심연의 환생의 불꽃(심연) 각각 **1회 사용 가격(메소)** 을 입력받는다.
- 해당 가격은 큐브 가격·주문의 흔적 가격과 동일한 개념(메소 단위)이며, **평균 확률·기대 횟수와 곱해 평균 비용**을 산정한 뒤 시뮬레이션/결과에 제공한다.

## UI 요구사항

- **입력 필드** (위 → 아래 순서)
  1. **강력한 환생의 불꽃**: 가격(메소) 입력, **초기값 100,000**
  2. **영원한 환생의 불꽃**: 가격(메소) 입력, **초기값 2,000,000** — 라벨 옆에 **"(메소 동일)"** 문구만 표기
  3. **심연의 환생의 불꽃**: 가격(메소) 입력, **초기값 10,000,000**

- 원가와 가격은 동일한 의미(1회 비용 메소)로 하나의 입력만 사용한다.

## 아키텍처

- 가격 상태는 보너스 스탯 계산기(bonus-stat-calc)의 atoms에 두고, 기댓값/시뮬 로직에서 **기대 횟수 × 해당 방법 가격**으로 비용을 산정한다.
- item-scouter는 BonusStatIntegration을 통해 bonus-stat-calc의 SettingSectionContent를 사용하므로, 가격 입력 UI는 bonus-stat-calc의 설정 섹션에 추가한다.

## 검증

- 세 방법 모두 초기값이 위와 같이 노출되는지, 영환 라벨에만 "(메소 동일)"이 보이는지 확인.
- (추후) 평균 비용 산정 및 시뮬 반영 여부 확인.
